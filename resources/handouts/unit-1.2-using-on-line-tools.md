[Unit 1.2.1 Using Alpheios]{.ul}

The Alpheios browser extension will be the single most useful tool in
learning Greek. It is available for free, it downloads in seconds, and
it gives you the morphology and meaning of any Greek word in an xml
file. It also links to dependency syntax trees, where they are
available. The only thing not provided by Alpheios is a translation,
which is readily available elsewhere. Until we get through the grammar
and start tackling genuine texts, you will be provided with translations
and commentary for all practice sentences.

Go to <https://alpheios.net/> \> Our Tools \> With the browser extension
from your desktop \> Install Now

Go back to the main page and click on Resources \> Tutorials

Watch the Getting Started video for your browser \[I use Chrome\]

Watch "General Features" and "Alpheios Toolbar" at a minimum. Watch as
many of the others as you like.

Create a log in, if you wish.

[Unit 1.2.2 Using Perseids to Make Dependency Trees]{.ul}

The Perseids Project \[perseids.org\] is, according to its website, "a
free and open online environment for producing data-driven editions of
ancient documents. The Platform allows users to collaborate on editing
and publishing documentary materials from the ancient world." Its most
robust tools are used for text alignments and for treebanking. We will
be using dependency syntax trees as a way of explaining the grammatical
structure of a given sentence.
